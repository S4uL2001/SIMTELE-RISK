# SIMTELE-RISK · Módulo 4

Reconstrucción Numérica y Auditoría de Telemetría Dual (viento y tensión) ante pérdida de señal.

> **Datos sintéticos. Aplicación exclusivamente educativa. No es un sistema de control ni de seguridad certificado.**

## Stack
React · TypeScript · Vite · Tailwind · Plotly.js · Supabase · Vitest

## Ejecutar en GitHub Codespaces
```bash
npm install
npm run dev      # http://localhost:5173
npm run test
npm run build
